Project

Solana Wallet Transactions

Python · SQL · PostgreSQL · Supabase · Jun – Jul 2026

I built this project out of personal interest in blockchain data. I wanted to see what I could actually pull from a live wallet and do something useful with it, rather than just reading about how it works.

Using Python, I connected to the Solana API and pulled 500+ transactions from a wallet, parsing each record into a PostgreSQL database hosted on Supabase. Getting the data to land cleanly in the database took more work than expected — the API responses had inconsistent fields depending on the transaction type, so I had to handle edge cases as I went.

Once the data was in, I wrote SQL queries to track things like transaction counts, fee totals in both SOL and USD, active trading days, and the most-used token across all activity. It was a good exercise in thinking through what questions are actually worth asking before writing the query.

The most interesting part was connecting a live pricing API to calculate real-time USD values for each token. I then visualized this as an interactive bubble chart, which made it a lot easier to see which tokens had the most volume and value at a glance versus just reading rows in a table.

This was my first project working with blockchain data end-to-end. It gave me a practical understanding of how on-chain data is structured, how to move it into a relational database, and how to build something visual on top of it.
