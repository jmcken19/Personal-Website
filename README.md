# Personal Website

Rebuilding my personal portfolio site from scratch.

## Project Structure
- `index.html`: Home page featuring the "About Me" bio and profile image placeholder.
- `resume.html`: Interactive, typed-out resume with responsive formatting.
- `volleyball.html`: Placeholder page for volleyball content.
- `style.css`: Modern, clean styling utilizing a warm neutral color palette.
- `script.js`: Minimal JavaScript footprint.
- `/assets`: Media, documents, and other static assets.

## Color Palette
Strictly styled with the following custom warm neutrals:
- Background: `#F2F0EF`
- Contrast Accents: `#CFC6C2`, `#AC9F98`, `#847A75`, `#5F5853`
- Text & Dark Elements: `#3C3734`, `#1C1918`
